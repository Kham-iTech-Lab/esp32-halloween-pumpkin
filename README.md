# ไฟฟักทองฮาโลวีน ESP32 🎃

ไฟ LED ในฟักทองที่ไหวเหมือนเปลวเทียน ไม่ต้องใช้ไฟจริง และกดเปลี่ยนเป็นสีม่วงหรือเขียวผีจากมือถือได้

จากคลิป **K iTech Review** (TikTok) · **Kham iTech Lab** (YouTube / Facebook)

## ของที่ใช้

| ชิ้น | หมายเหตุ |
|---|---|
| บอร์ด ESP32 | รุ่นไหนก็ได้ (ESP32, S3, C3) |
| LED WS2812B | แบบวงกลม 12 ดวง หรือแบบเส้น |
| ตัวต้านทาน 330Ω | ต่อคั่นสายสัญญาณ |
| พาวเวอร์แบงก์ 5V | ใช้ไฟ 5V จากพอร์ต USB |

## ต่อสาย

| WS2812B | ต่อเข้า |
|---|---|
| 5V | 5V ของพาวเวอร์แบงก์ หรือขา 5V/VIN ของบอร์ด |
| GND | GND (กราวด์ร่วมกับ ESP32) |
| DIN | GPIO 5 ผ่านตัวต้านทาน 330Ω |

## ติดตั้ง

1. เปิด Arduino IDE ติดตั้งบอร์ด ESP32 (Boards Manager → esp32 by Espressif)
2. ติดตั้งไลบรารี **Adafruit NeoPixel** (Library Manager)
3. เปิดไฟล์ `halloween_pumpkin/halloween_pumpkin.ino`
4. แก้ `NUM_LEDS` ให้ตรงกับจำนวนดวงที่มี
5. ถ้าอยากต่อ Wi-Fi บ้าน ใส่ `WIFI_SSID` กับ `WIFI_PASS` (เว้นว่างไว้ก็ได้)
6. อัปโหลด แล้วเปิด Serial Monitor ที่ 115200

## เปลี่ยนสีจากมือถือ

- **ไม่ได้ใส่ Wi-Fi บ้าน**: ต่อ Wi-Fi ชื่อ `Pumpkin-ESP32` รหัส `halloween` แล้วเปิด `http://192.168.4.1`
- **ใส่ Wi-Fi บ้านแล้ว**: เปิด IP ที่ขึ้นใน Serial Monitor หรือ `http://pumpkin.local`

มี 4 ปุ่ม: เปลวเทียน · ม่วง · เขียวผี · ปิดไฟ

## ปรับแต่ง

- `MAX_BRIGHT` ความสว่างสูงสุด (0–255) ตั้งไว้ 160 เพื่อไม่ให้กินไฟเกินพาวเวอร์แบงก์
- `PALETTES` สีตอนมืดสุดกับสว่างสุดของแต่ละโหมด
- ใน `flickerStep()` เลข `12` คือความถี่ที่เปลวไฟเปลี่ยน เพิ่มแล้วไหวถี่ขึ้น

## ข้อควรระวัง

- LED 12 ดวงที่สว่างเต็มกินไฟได้ถึงราว 0.7A ถ้าใช้แบบเส้นยาวหลายสิบดวง ให้ลด `MAX_BRIGHT` หรือใช้แหล่งจ่ายไฟแยก
- อย่าวางใกล้ของติดไฟ และอย่าให้ฟักทองเปียกโดนบอร์ด
